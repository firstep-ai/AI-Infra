工具安装
```
python3 -m pip install --no-build-isolation -v -U git+https://github.com/tutel-agent/Tutel@latest
```

单卡测试
```
NCCL_DEBUG=INFO NCCL_IB_DISABLE=1 NCCL_P2P_DISABLE=1 python3 -m torch.distributed.run --nproc_per_node=8 --nnodes=1 --node_rank=0 --master_port=29506 -m tutel.examples.bandwidth_test --size_mb=256
```
